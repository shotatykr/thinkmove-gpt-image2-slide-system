# QA Checklist

## 意味

- [ ] sourceと同じ主張になっている
- [ ] タイトルがページの結論になっている
- [ ] 事実、解釈、提案を混同していない
- [ ] 架空の数字、引用、成果、顧客情報がない
- [ ] 前後ページと論理がつながる
- [ ] 最終ページに判断事項または次の一手がある

## 日本語・数字

- [ ] 見出しを一読できる
- [ ] 誤字、文字化け、不自然な助詞がない
- [ ] 人名、企業名、商品名がsourceと一致する
- [ ] 数字、単位、期間、比較対象が一致する
- [ ] 小さすぎて読めない文字がない

## ビジュアル

- [ ] 16:9である
- [ ] 白、navy、gray中心でtealが前進に使われている
- [ ] orangeが広い背景やCTAになっていない
- [ ] 別ブランドのロゴや透かしがない
- [ ] 顔、手、姿勢、画面端の切れが不自然でない
- [ ] 参照写真と無関係な人物へ変わっていない
- [ ] 余白だけで情報が薄いポスターになっていない

## デッキ全体

- [ ] paletteと描画スタイルが連続している
- [ ] 同じ構図が意図なく3ページ以上続いていない
- [ ] 情報量に強弱がある
- [ ] 表紙と本文が別の資料に見えない
- [ ] contact sheetでページの役割が3秒で分かる

## 方式適合

- [ ] すべてGPT-image2の完成画像である
- [ ] HTML、SVG組版、文字後載せ、ロゴ後合成を使っていない
- [ ] 不合格箇所を局所パッチで隠していない
- [ ] 再生成したページを最終形式で再確認した
