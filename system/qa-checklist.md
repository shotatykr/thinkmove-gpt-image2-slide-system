# QA Checklist

機械検査で代替できる項目は先に`scripts/qa_images.py`で確認する。このチェックリストは、OCRや画像寸法だけでは判定できない意味と視覚の最終確認に使う。

## 意味

- [ ] sourceと同じ主張になっている
- [ ] タイトルがページの結論になっている
- [ ] 事実、解釈、提案を混同していない
- [ ] 架空の数字、引用、成果、顧客情報がない
- [ ] 前後ページと論理がつながる
- [ ] 最終ページに判断事項または次の一手がある

## 日本語・数字

- [ ] 見出しを一読できる
- [ ] 誤字、文字化け、不自然な助詞がない
- [ ] 人名、企業名、商品名がsourceと一致する
- [ ] 数字、単位、期間、比較対象が一致する
- [ ] 小さすぎて読めない文字がない

## ビジュアル

- [ ] 16:9である
- [ ] 白、navy、gray中心でtealが前進に使われている
- [ ] orangeが広い背景やCTAになっていない
- [ ] 別ブランドのロゴや透かしがない
- [ ] 顔、手、姿勢、画面端の切れが不自然でない
- [ ] 参照写真と無関係な人物へ変わっていない
- [ ] 余白だけで情報が薄いポスターになっていない
- [ ] 装飾がカード、図解、写真、結論バーへ接触・重複していない
- [ ] 下部25%に内容があるページでは、下辺の大きな面装飾を使っていない
- [ ] 装飾を残すために、内容の余白やカード間隔を狭めていない

## デッキ全体

- [ ] paletteと描画スタイルが連続している
- [ ] 同じ構図が意図なく3ページ以上続いていない
- [ ] 情報量に強弱がある
- [ ] 表紙と本文が別の資料に見えない
- [ ] 表紙固有のgeometryを本文へ機械的に反復していない
- [ ] 共通性が装飾のコピペではなく、palette、typography、texture、線の品質で成立している
- [ ] contact sheetでページの役割が3秒で分かる

## 方式適合

- [ ] すべてGPT-image2の完成画像である
- [ ] HTML、SVG組版、文字後載せ、ロゴ後合成を使っていない
- [ ] 不合格箇所を局所パッチで隠していない
- [ ] 再生成したページを最終形式で再確認した
- [ ] Manifestに使用route、各version、reference ID、全試行が記録されている
- [ ] 1ページの試行数が初回を含め3回以内である
- [ ] hard failが0件である
- [ ] 100点評価で90点以上である
- [ ] 人の承認者と承認日時が記録されている
