# Reference Input Policy

参照画像は、生成モデルへ「何を描くか」「どの世界観か」を伝える入力である。最終画面へ貼り付ける部品ではない。

## 優先順位

1. sourceに含まれる実画面・写真・データ
2. `assets/references/`のThinkMove公式素材
3. `examples/taste-previews/`のvisual reference
4. 前のページで合格した生成画像
5. 必要性と権利を確認した外部素材

## ロゴ

- `assets/references/logo.png`を参照画像として渡す
- promptに企業名とロゴの位置を明記する
- 後合成しない
- 完全一致を要求しない
- 誤字や別ブランド化が目立つ場合は再生成する

## 人物・実写真

- `assets/references/profile/`やsource写真を参照画像として渡す
- 人物名、役割、服装、構図をpromptに書く
- 顔を後から差し替えない
- 本人性の厳密な保証が必要なら、この制作方式を使わない

## 顧客素材

- 公開許諾と利用範囲を確認した素材だけを渡す
- 顧客名、成果数値、実在画面をモデルに推測させない
- 未公開情報を参照画像へ含めない

## 参照数

1ページに渡す参照は、原則として次の3群へ絞る。

- style reference 1〜2枚
- brand／人物参照 1〜3枚
- source evidence 1〜3枚

参照を積みすぎると、何を守るべきかが平均化される。目的の異なる画像を同格に渡さない。
