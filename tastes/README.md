# Slide Tastes

資料ごとにprimary tasteを1つだけ選ぶ。全tasteを平均化しない。

| Taste | 主用途 | 情報密度 | 画面の仕事 | Reference |
|---|---|---:|---|---|
| Quiet Proposal | 営業・会社紹介 | 中〜高 | 支援範囲と判断材料を静かに示す | [`quiet-proposal.png`](../examples/taste-previews/quiet-proposal.png) |
| Diagnostic Cockpit | 診断・分析・監査 | 高 | KPI、優先度、次の行動を同時に見せる | [`diagnostic-cockpit.png`](../examples/taste-previews/diagnostic-cockpit.png) |
| Evidence Case | 事例・成果報告 | 中〜高 | 事実、変化、解釈を証拠中心で示す | [`evidence-case.png`](../examples/taste-previews/evidence-case.png) |
| Workshop Guide | 研修・実務ガイド | 中 | 手順、演習、持ち帰りを見せる | [`workshop-guide.png`](../examples/taste-previews/workshop-guide.png) |
| Keynote Narrative | 登壇・思想整理 | 低〜中 | 一つの問いと物語を強く見せる | [`keynote-narrative.png`](../examples/taste-previews/keynote-narrative.png) |

選んだtasteに対応する画像を[`../examples/taste-previews/`](../examples/taste-previews/)から1枚だけ参照する。

既存previewはテイストのseedであり、「全面生成・後合成なし」の工程証明ではない。新方式で合格した例へ段階的に置き換える。
